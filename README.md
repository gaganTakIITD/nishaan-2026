# NISHAAN 2026

Inclusive cultural fest website for IIT Delhi — Office of Accessible Education.

## Run locally

```bash
cd nishaan-2026
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — serve production build
- `npm run lint` — ESLint

## Stack

Next.js App Router · TypeScript · Tailwind CSS · Framer Motion · first-party accessibility toolbar
